Implementation instructions for user management:

Scan through the backend codebase and implement the user management endpoints in the backend API

1. Backend

a. Create user management endpoints in the backend API
    - Create user
    - Update user
    - Delete user - (soft delete only accessible to the super admin)
    - Get all users - paginated with optional query parameters
    - Get user by id
b. Add these endpoints to the swagger documentation

2. Portal
Create user management pages in the portal
    - Create user - Use a modal to create a user
    - Update user - Use a modal to update a user
    - Deactivate user - (This should call the delete user endpoint)
    - Create a modal to view the user details
    - Get all users and show them using the existing datatable
    - Add a search bar to the datatable to search for users
    - Add a filter to the datatable to filter users by role
    - Add a pagination to the datatable to paginate users
    - Add a sorting to the datatable to sort users
    - Add a deactivate button to the datatable to deactivate users
    - Add a view button to the datatable to view users
    - Add a create button to the datatable to create users
    - Add an update button to the datatable to update users
    - Add a deactivate button to the datatable to deactivate users
